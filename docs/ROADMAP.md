# DeBrowser 路线图

本文档记录 DeBrowser 的产品功能清单与交付状态，是功能范围的唯一记录。系统实现见 [ARCHITECTURE.md](ARCHITECTURE.md)，面向用户的变化记录见 [CHANGELOG.md](../CHANGELOG.md)。

状态含义：

- **已交付**：功能已经实现并进入当前稳定代码。
- **部分交付**：只有部分范围实现，具体范围在说明中注明。
- **计划中**：尚未实现，已确定要做。
- **暂不支持**：当前产品明确不提供。

## 项目目标

DeBrowser 是一款本地优先、便携的 Windows 桌面应用，用于管理多个相互隔离的浏览器实例：每个实例独占一个 Profile，可独立启动、运行与关闭；在此基础上提供代理节点绑定、书签管理与多开同步。设计目标是稳定、简单、可靠、容易维护；全部数据只保存在用户本机的便携目录内，不依赖任何外部服务器。

## 已交付功能说明

- **应用基础与生命周期**：全部数据位于可执行文件旁的便携目录（`data/`、`webview2-data/`、`config/`），不写入系统应用数据目录，不扫描或迁移外部数据；第二次启动只唤起已运行实例的窗口；关闭时按固定顺序释放资源，DeBrowser 退出不关闭用户浏览器。
- **浏览器实例管理**：实例以名称标识并自然排序；新建实例时实际建立实例文件（默认顺序编号、永不复用，或自定新建，或绑定保留的未绑定文件夹）；编辑时可重命名实例文件或更换绑定；删除默认保留实例文件。
- **浏览器内核手动登记**：「浏览器内核」页面登记本机程序，只保存路径与显示名，不做任何身份、版本或存在性检查；被实例引用的登记不可移除。
- **Profile 隔离**：每个实例以自己的文件夹作为浏览器用户数据目录运行；活动 Profile 不在浏览器使用期间被复制；删除实例文件有严格的受管目录证明与对象锚定删除保护。
- **浏览器运行管理**：进程身份以 PID、创建时间、可执行路径与命令行四项核验；用户直接关窗或浏览器崩溃都会被感知；应用重启后重新识别仍在运行的实例，无法确认时冻结可能危及数据的操作。
- **代理配置**：内置 Mihomo 核心在首次启动时从官方发布下载并双重校验，存放在 `data/mihomo/`，只管理 DeBrowser 自己启动的核心进程，不影响用户自行安装的 Clash/Mihomo。订阅与本地 YAML 配置导入后解析为节点统一管理；每个实例可绑定不同节点，经专属本地监听端口直达所选节点，未绑定实例直连；核心未启动时已绑定实例拒绝启动而不静默直连。节点可手动测速（实际连接测试，显示延迟或不可用）。
- **书签管理**：书签资源库（文件夹树）与实例真实书签完全独立、互不自动回写；分发同步为合并语义（只增不删、同 URL 跳过、同名文件夹复用）；真实书签通过直接读写已确认停止实例的 Chromium 原生书签文件管理，写入有原子替换与恢复副本保护；聚合搜索只显示名称、网址与不同实例数量。
- **多开同步**：一个主控实例与多个跟随实例之间，经各自的回环 CDP 连接同步标签页创建、关闭、切换与已提交的导航、刷新；支持窗口排列与主窗口镜像；跟随实例故障相互隔离。
- **日志系统**：运行（保留 30 天）、操作（保留 90 天）、错误（保留 90 天）三类 JSONL 记录，以操作号关联；总容量用户可配（默认 100 MB），超出自动清理最早记录；数据管理页可按类别与日期范围导出，导出前做敏感性扫描。日志不记录 Cookie、密码、Token、浏览器历史或网页内容。
- **系统设置**：浅色（默认）、暖色、深色三套主题即时切换并持久化；日志总容量可设置；当前版本不支持自定义数据路径（便携目录由应用位置决定）。

## 后续计划

### 程序内更新

计划中，尚未实现。设想方式：通过 GitHub Releases 检查与下载更新，更新前验证下载内容，更新过程保留全部便携数据，失败时回滚到更新前状态。在该功能交付前，用户只能通过重新获取完整应用文件夹的方式更新（便携数据位于应用文件夹内，替换程序文件时注意保留 `data/`、`webview2-data/` 与 `config/`）。具体发布渠道与签名方案确定后再补充到本文档与 README。

### 完整备份与恢复

计划中，尚未实现，是最后一个计划中的功能。设想要点：

- 用户主动创建备份包（带清单与逐文件校验），覆盖完整的用户数据（数据库、实例文件、设置与凭据引用）。
- 备份使用独立备份口令加密，使备份能跨机器、跨 Windows 用户恢复（现有的 DPAPI 凭据保护本身不具备跨机器能力）。
- 恢复先在暂存区完整校验，之后才替换当前数据；恢复失败时当前数据不受影响。

注意区分：数据库迁移前自动生成的快照（见 [DATABASE.md](DATABASE.md)）是数据层内部的安全设施，只用于升级保护，不是面向用户的备份与恢复功能。

## 暂不支持或明确排除的功能

- **独立 Chromium 的下载、安装与管理**：不提供。DeBrowser 只登记和使用用户本机已有的浏览器程序。
- **浏览器指纹隔离**：不提供，不做相关宣称。
- **首次启动欢迎页与外部数据导入**：不提供。应用直接启动并初始化便携目录，不扫描、不检测、不自动迁移其他位置的数据。
- **代理规则系统与运行模式**：不提供。代理模块只做节点导入、实例绑定与直达连接，不提供规则集、自定义规则或全局/规则/直连模式切换。
- **非 Chromium 浏览器书签**：不支持读写 Firefox 等非 Chromium 的书签存储。
- **其他平台**：仅支持 Windows 11 x64，不提供 macOS、Linux 或 Windows 其他版本的构建。
- **英文界面**：界面仅简体中文，不提供英文语言包或语言切换。
