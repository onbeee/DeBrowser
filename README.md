# DeBrowser

一款轻量、本地优先的 Windows 桌面应用，用于管理多个相互隔离的浏览器实例。每个实例拥有独立的 Profile（实例文件），可以独立启动、运行和关闭，彼此不共享数据。

DeBrowser 面向 **Windows 11 x64**，设计目标是稳定、简单、可靠、容易维护。

## 功能概览

- **浏览器实例管理**：创建、编辑、删除实例；名称自然排序；批量选择、批量启动/关闭/删除与批量创建。
- **独立 Profile**：每个实例绑定一个独立的实例文件（`data/profiles/` 下的文件夹），创建时实际建立（默认顺序编号 P-1、P-2……永不复用，或自定新建，或绑定保留的未绑定文件夹），编辑时可重命名或更换绑定。删除实例默认只删记录、保留实例文件。
- **浏览器登记**：用户在「浏览器内核」页面手动登记本机浏览器（纯路径登记，见下），实例按登记关联并启动真实浏览器进程；进程身份经严格核验，DeBrowser 重启后可重新识别仍在运行的实例。
- **统一日志**：运行、操作、错误三类记录自动保存并按操作关联，可在「数据管理」页按类别与日期范围导出；日志总容量可由用户设置（默认 100 MB），超出自动清理最早记录。日志是唯一的记录系统。
- **多开同步**：多个运行中的实例之间同步标签页与页面操作（主控实例的操作经 CDP 同步到跟随实例），并支持窗口排列与主窗口镜像。
- **代理配置**：内置 Mihomo 核心（首次启动时从官方发布下载并校验），可导入订阅或本地 YAML 配置并解析节点，为每个实例绑定不同节点；已绑定实例经专属本地监听端口使用所选节点，未绑定实例直连。
- **界面**：侧边栏固定七项（浏览器实例、代理配置、浏览器内核、书签管理、多开同步、数据管理、系统设置），启动后默认进入「浏览器实例」；仅简体中文；浅色、暖色、深色三套主题，首次启动默认浅色，选择会持久化。
- **全局通知**：操作结果统一进入顶栏「通知台」显示（最近 80 条，最新在前，可展开批量操作的逐项结果）；其中的重点结果同时以右上角浮窗提醒（统一显示 3 秒，同时最多 3 条，新浮窗立即顶掉最早一条）。通知只存在于内存中、不做持久化，与「数据管理」的日志系统相互独立：日志负责长期记录与导出，通知负责即时展示。

## 产品范围

- **纯路径登记**：DeBrowser 不自动检测浏览器（不扫描注册表、不扫描磁盘）。用户在文件选择器中任选一个程序可执行文件，DeBrowser 只保存其路径和显示名，不做任何身份、版本、签名、发布者或存在性检查；移除登记只删除数据库记录。
- **代理模块（重新设计，已交付）**：「代理配置」页面可启动/关闭内置 Mihomo 核心，导入订阅或本地 YAML 配置并解析其节点，为每个浏览器实例绑定不同节点（实例编辑页可同步修改同一份绑定）；已绑定实例经专属本地监听端口使用所选节点，未绑定实例直连。此前的历史代理实现与 PR #27 的复杂方案均不属于本实现。
- **不提供**独立 Chromium 的下载、安装和管理。
- 尚未交付的功能（程序内更新、完整备份与恢复）不提供入口，不使用假数据冒充。

## 下载与使用

项目尚未发布正式版本，目前没有可供下载的安装包或便携包；现阶段只能从源码构建运行，构建与开发流程见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。正式发布渠道确定后，本节会更新为真实的下载与启动说明，不在此预先承诺。

DeBrowser 按便携方式设计使用：应用文件夹放在哪里，程序与全部数据就都在哪里（见下文「数据与隐私」的目录结构）。运行 `debrowser.exe` 即直接启动，没有欢迎页或首次启动选择页；要管理哪个浏览器，由用户在「浏览器内核」页面手动登记本机已安装的程序。

## 系统要求

- Windows 11 x64。
- WebView2 运行时（Windows 11 已预装）。
- 至少一个由用户自行安装的浏览器程序（DeBrowser 不自带浏览器，只登记和使用本机已有程序）。

## 数据与隐私

DeBrowser 是便携优先、本地优先的：所有数据都位于可执行文件旁边，应用文件夹放在哪里，数据就跟到哪里。

```text
<应用文件夹>\
  debrowser.exe
  data\            debrowser.db、backups\、logs\、profiles\、mihomo\、secrets.vault
  webview2-data\   应用窗口的 WebView2 用户数据
  config\          settings.json（语言、主题、日志容量）
```

- 任何内容都不写入 `%AppData%` 或 `%LocalAppData%`；文件夹不可写时应用明确报错，不把数据悄悄存到别处。
- 首次启动直接创建便携数据目录并初始化，不提供欢迎页或选择页，也不从任何其他位置扫描、检测或迁移数据。
- 凭据 Vault 使用 Windows DPAPI（CurrentUser）保护。DPAPI 绑定的凭据不能保证在另一台 Windows 电脑或另一个 Windows 用户下仍可解密；受影响的条目会被保留但标记为不可用，需要重新录入。跨机器的完整迁移与恢复属于 Stage 12（使用独立备份口令），尚未交付。
- 用户数据库、浏览器 Profile、Cookie 与凭据永不提交到本仓库。
